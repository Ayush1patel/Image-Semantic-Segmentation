## Observations

- Consistently the weakest three: **Traffic_Barrier (55%)**, **Sedan
  (56%)**, **Truck (68%)** — same ranking as the earlier epoch-45
  snapshot, i.e. the model's relative difficulty ordering across classes
  is stable as training progresses, not noisy/random. This is what
  genuine, non-degenerate learning looks like.
- Precision consistently trails recall on the hardest classes (e.g.
  Traffic_Barrier: 59% precision vs 88% recall) — the model over-predicts
  these classes (false positives), a plausible side effect of the
  aggressive median-frequency class weighting (rare classes weighted up
  to 10x in the loss).
- All 18 non-background classes improved from the epoch-45 snapshot to
  epoch-66 (mean IoU 0.7975 -> 0.8149), consistent with a model still
  learning, not overfit/saturated noise.
